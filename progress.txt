## How to Run
1. .\venv\Scripts\activate
2. pip install -r backend/requirements.txt
3. $env:DATABASE_URL="sqlite:///./incident_triage.db"; .\venv\Scripts\python.exe -m backend.seed
4. $env:DATABASE_URL="sqlite:///./incident_triage.db"; .\venv\Scripts\python.exe -m uvicorn backend.main:app --port 8888
5. Open http://localhost:8888

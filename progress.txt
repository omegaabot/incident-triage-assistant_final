=======================================================================
1. WHAT IS THIS PROJECT?
=======================================================================

A deterministic, rule-based incident triage engine built with FastAPI.
It ingests monitoring alerts (JSON), runs dual-track analysis (rules +
risk scoring), detects false positives, assigns severity, and pages the
right on-call engineer — all in under a second with zero ML.

4. KEY FEATURES
=======================================================================

  1. Dual-Track Triage Engine
     - Parallel rule + risk analysis
     - Configurable rule conditions per alert type
     - Weighted risk scoring (0-120)

  2. False Positive Detection
     - Signal-based confidence scoring
     - >50% confidence → auto-suppress escalation
     - Keeps genuine threats visible

  3. Automated Escalation
     - Severity → escalation level mapping
     - On-call engineer matching by team/level
     - Runbook suggestions per incident type

  4. Dashboard & Reports
     - Real-time KPI cards (total alerts, crit/high, FP, active rules)
     - Alert feed with severity badges
     - Severity donut chart & timeline
     - PDF export (clean modern theme)
     - CSV export

  5. Rules Management
     - Full CRUD for triage rules
     - Enable/disable individual rules
     - Bulk import from JSON
     - Per-rule FP signals configuration

  6. Playbooks / Runbooks
     - Library of incident response runbooks
     - Trigger conditions per playbook
     - Step-by-step resolution guides

  7. Anomaly Detection
     - Z-score based metric analysis
     - Periodic baseline recomputation
     - Supports latency, traffic, error rate fields

6. RUNNING THE PROJECT
=======================================================================

  cd backend
  pip install -r requirements.txt
  uvicorn backend.main:app --host 0.0.0.0 --port 9988

  Open http://localhost:9988 in browser.

  API endpoints:
    GET  /                  → Dashboard
    GET  /triage            → Triage page
    POST /triage            → Submit alert for triage
    GET  /rules             → Rules management page
    POST /rules             → Create new rule
    GET  /playbooks         → Playbooks page
    GET  /report            → Reports page
    GET  /report/pdf        → Download PDF report
    GET  /report/csv        → Download CSV report
    GET  /history           → Alert history
    GET  /api/stats/summary → JSON stats summary
    GET  /api/stats/timeline→ JSON timeline data
